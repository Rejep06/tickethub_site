# Tickethub — обновление каталога и подготовка развёртывания

Начните с нужной инструкции:

- **Уже работающий локальный проект:** `UPDATE_tickethub_checkout.md`.
- **Новый сервер с доменом:** `DEPLOY_tickethub.md`.
- **Результаты фактических проверок:** `VERIFICATION_tickethub_checkout.md`.
- **Изменённые файлы и SHA-256:** `CHECKOUT_MANIFEST.json`.

Обновление сделано поверх присланного `tickethub.zip`. Backend и frontend — одна версия, требуется новая миграция. Она снимает с публикации непроверенные импортированные события; не удаляет данные. Сделайте резервную копию до установки.

Категории, фотографии и тексты должны быть заполнены реальными данными. В архиве нет новых вымышленных мероприятий, продаж, отзывов или фотографий команды. Демонстрационные данные в вашей существующей базе нужно снять с публикации самостоятельно.

Проект не объявляется проверенным production-релизом: full typecheck, сборка Next, Django/PostgreSQL и сквозные сценарии должны пройти на вашем стенде. Контейнерная сборка не пропускает проверки ради запуска. Реальные env, пароли, сертификаты, node_modules и .next не включены.

Прежние README и отчёты сохранены как история проекта. Для новых возможностей и единого развёртывания ориентируйтесь на эти корневые документы.
