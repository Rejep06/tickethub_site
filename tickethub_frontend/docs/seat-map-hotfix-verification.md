### Браузерные проверки: что запускалось на самом деле

Использован Chromium через Python Playwright. В браузере исполнялись скомпилированные TypeScript исходники компонентов и доменных модулей из проекта, а не нарисованная копия интерфейса. Проверялись настоящие DOM-события мыши, нативный Canvas, ResizeObserver, requestAnimationFrame и события касания через Chrome DevTools Protocol.

Из-за недоступности npm использовался **имеющийся локально React 18.2.0 production** из установленного JupyterLab. Для воспроизведения дефекта lifecycle стенд явно выполнял **cleanup всех зарегистрированных эффектов → повторный setup**, сохраняя состояние и refs. Это имитация соответствующего цикла StrictMode, **не запуск development-сборки React 19.3.0**.

Оболочка Next Image/Link, маршрутизатор, query-слой и API редактора заменены тестовыми адаптерами. Тестовый фон — SVG с известными размерами, геометрия — 768 вымышленных мест. Стенд не подключался к настоящему Django и не использовал пользовательскую базу. Полноценные тесты с настоящим StrictMode на React проекта добавлены в Vitest, но здесь не выполнены.

### Воспроизведено на прежнем коде

1. После повторного cleanup/setup кнопка `+` не меняет ни transform фонового слоя, ни пиксели Canvas. Остаётся `translate(0px, 0px) scale(1)`.
2. Импортированное место с пустым рядом вызывает `INVALID_SEAT_LABEL` при открытии SeatWorkspace.

### Проверено на исправленном коде

* Первоначальный fit показывает 100%, реальные пропорции уже загруженного фонового SVG не сбрасываются.
* `+`/`−` меняют фон и контрольный снимок пикселей Canvas, не только индикатор.
* Неактивная карта не забирает колесо у страницы. После активации wheel zoom сохраняет точку под фактическими координатами события.
* Перетаскивание мышью, двойной клик, стрелки клавиатуры, Escape и возврат к общей схеме работают.
* Выбор сектора меняет камеру. Клик по увеличенному месту открывает именно его номер; кнопка выбора вызывает нужный callback. Недоступное место выбрать нельзя.
* Обновление наличия не сбрасывает камеру и не меняет API-геометрию. Повторное монтирование и изменение ширины не блокируют дальнейший масштаб.
* Два контакта touch увеличивают карту, один палец перемещает её. Отменённый touch не выбирает место и не блокирует управление.
* Редактор открывает неполные данные, не выполняет автосохранение и не разрешает публикацию проблемной схемы.
* Исправление одного места при другой неполной записи работает. Отправляется один update с исходным ID и `expected_version: 7`, без create/delete и без переписывания второй записи.

Подробности: `docs/seat-map-hotfix-evidence/browser-report.json` и `browser-run.log`.

## Сохранённые ограничения безопасности

`reactStrictMode` не отключён. CSRF, session cookies, trailing slash и бизнес-проверки backend не изменены. Новый код не удаляет проблемные места автоматически и не назначает им выдуманную нумерацию. Строгая проверка остаётся на пути записи новых/изменённых мест, а не открытия сохранённой схемы.
