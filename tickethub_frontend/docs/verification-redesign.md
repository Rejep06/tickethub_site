## Что доказывают проверки URL

Тесты вызывают настоящий `api()` с перехватом fetch и проверяют адрес, CSRF, метод, тело и Idempotency-Key. Отдельно проверяются общая нормализация пути, серверное построение `new URL`, язык и защита от ошибочных путей.

```text
/api/v1/me/?lang=ru
/api/v1/public/config/?lang=ru
/api/v1/auth/csrf/
```

Тест конфигурации Next подтверждает наличие явного `/` в destination и `skipTrailingSlashRedirect: true`. Он **не заменяет** реальную проверку rewrite. В `tests/e2e/appearance.spec.ts` добавлена такая проверка на работающем приложении: чтение config/CSRF без разрешения редиректа, поиск через UI и проверка браузерных URL. В этой среде E2E не выполнялся.

## Граница проверки вёрстки

Для проверки размеров использовались исходные TSX-компоненты и CSS, отдельный вспомогательный сериализатор JSX и Chromium. Зависимости React/Next/иконки/хуки в этом вспомогательном рендере заменялись изолированными адаптерами. Это позволяет увидеть композицию, логотип, цвета и горизонтальное переполнение, но **не проверяет** гидратацию React, работу Next, клики приложения, авторизацию или backend.

Страницы home/about/FAQ проверены без добавления фиктивных мероприятий. Для home использован пустой каталог. Полученные PNG — предпросмотры вёрстки, а не скриншоты работающего Next-приложения. Сам вспомогательный рендер не входит в production-код.

В `docs/redesign-evidence/` сохранены выводы выполненных команд и измерения изолированной вёрстки. Исторический отчёт первоначальной версии — `verification-original.md`.

## Что проверить на компьютере с установленными зависимостями

```powershell
npm test
npm run check:translations
npm run typecheck
npm run lint
npm run test:components
npm run build
```

Для интерфейса: `npm run dev`, затем `npm run test:e2e -- tests/e2e/appearance.spec.ts` в другом терминале. Next и Django должны быть запущены; config и CSRF доступны. Старые write-E2E запускаются только с явным разрешением для одноразовой тестовой базы.

Сохранены прежние функциональные ограничения бэкенда из `backend-gaps.md`. Редизайн не добавляет онлайн-эквайринг или серверную выдачу файлов и не меняет денежные правила.
