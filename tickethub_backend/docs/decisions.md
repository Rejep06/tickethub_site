# Принятые решения

Приоритет: `docs/spec/04_current_instructions.txt` → Backend-ТЗ → исходный проект → прежняя архитектура. Сохранены оригинальные config/User/health/CSRF/error/request ID; они расширены, не заменены новым стеком. Полный список изменённых файлов: changes.md.

| Вопрос | Решение |
|---|---|
| Фоновые задачи | Нет Celery/Redis/worker-очереди. OTP SMTP синхронно; обычные письма on_commit с простым EmailLog и ручным retry; cron только для очистки/напоминаний. |
| Сотрудники | Стандартный пароль + Django session. MFA/TOTP не требуется в актуальном MVP. Клиентский OTP не даёт staff-доступа. |
| Запас | TicketUnit + CheckoutHoldItem + OrderItem, без Allocation. Короткая блокировка Event, constraints активных связей. |
| Возвраты | CustomerCase содержит решение; FinancialEntry отдельно фиксирует фактический возврат. |
| Аналитика | FunnelEvent + ORM/простые функции, без Journey, очередей и отдельного хранилища. |
| Деньги | Целые копейки, manual facts + immutable reversal. Нет PaymentGateway/заглушки; nullable created_by оставляет возможность будущей банковской интеграции. |
| Схемы | Черновик/публикация/копия версии; ручные координаты и проверка соседства. |
| Юридический контент | Версионированные страницы без придуманных текстов; development не блокируется их отсутствием, production требует утверждения перед новыми формами. |
| Отмена | Только через сервис. Таймер заказа никогда не освобождает единицы. Отправленные/возвращённые требуют проверки перед перепродажей. |
| Смена состава заказа | После создания состав/продажные цены неизменяемы. Новый согласованный состав оформляется новым заказом после урегулирования старого; автоматического переноса денег между заказами нет. |
| Staff settings | Настройки из env; секреты не редактируются и не выдаются через API. |
| Зависимости | Дополнительно только Pillow для изображений и phonenumberslite для международных номеров; остальные уже были в основе. Проверенного lock нет до реальной установки. |
| Миграции | Написаны вручную из деклараций моделей, не Django-generated. Контроль имён/графа/PK статический; настоящий makemigrations --check обязателен. |
| OpenAPI | Authored контракт в docs/openapi.yaml; runtime drf-spectacular включён, но не запущен/не сопоставлен. frontend-api.md — основной контракт интеграции. |

Оригинальное расширенное v2-ТЗ сохранено для контекста. Не объявляется, что все его прежние механизмы (Allocation, обязательная MFA, сложный outbox, переносы между заказами, более широкая аналитика) реализованы без изменения: последняя инструкция сознательно упрощает MVP.
